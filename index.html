🔄 VFD (VARIABLE FREQUENCY DRIVE) SIZING
Roman Urdu: VFD ka size motor FLC se 10-25% zyada lena chahiye. Heavy duty ke liye 1.5x tak. Cable length zyada ho to dv/dt filter lagayein.
⚙️ GEARBOX SIZING
Roman Urdu: Gearbox ka ratio = input RPM / output RPM. Service factor load ke hisaab se 1.0 se 2.5 tak. Torque output mein barhta hai, speed ghatti hai.
💨 BLOWER / FAN CALCULATOR
Affinity Laws: Flow ∝ Speed, Pressure ∝ Speed², Power ∝ Speed³. Speed 10% barhao → Power 33% barhta hai!
🏭 BELT CONVEYOR CALCULATOR
Roman Urdu: Conveyor motor HP nikalne ke liye capacity, speed, length, lift sab ka role hai. Incline angle 18° se zyada na rakhein — material wapas gir jayega.
🚀 STARTER SIZING (DOL / Y-Δ / SOFT / VFD)
Rule of Thumb: Motor < 5kW = DOL. 5-30kW = Star-Delta. >30kW = Soft Starter ya VFD. VFD best hai — smooth start, energy saving.
⚡ BREAKER SELECTION (ACB / VCB / MCCB / MCB)
Roman Urdu: Breaker ka rating load current se 1.25x zyada hona chahiye. Icu system ke short circuit se zyada ho. Type D motor ke liye (inrush current zyada).
📏 BUSBAR SIZING (Cu / Al)
Current Density: Cu = 1.0-1.6 A/mm², Al = 0.8-1.2 A/mm². IP54 enclosure mein derating 0.85-0.90x.
🔧 CABLE / WIRE SIZING
IEC Sizes: 1.5, 2.5, 4, 6, 10, 16, 25, 35, 50, 70, 95, 120, 150, 185, 240, 300 mm². Voltage drop 3% se kam rakhein.
📊 LOAD SCHEDULE / PANEL DESIGN
PF Correction: Capacitor kVAr = kW × (tan φ1 − tan φ2). Transformer 80% load pe best efficiency deta hai.
